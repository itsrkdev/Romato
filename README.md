# 🍅 Romato - Full Stack Food Delivery Application

Romato is a modern, responsive, and full-stack food delivery web application built using the MERN stack. It allows users to browse through a diverse menu, filter food items by categories, manage a shopping cart, and seamlessly place orders.

## 🚀 Live Demo

- **Romato:** [https://itsromato.vercel.app]

---

## ✨ Features

- **Dynamic Food Menu:** Browse items with category-based filtering.
- **Cart Management:** Add, remove, or update quantities of food items dynamically.
- **Responsive UI/UX:** Mobile-first design with smooth loading states (including custom Skeleton Loaders).
- **Text-Truncation (UI Enhancement):** Clean typography that handles long item descriptions and titles gracefully using modern CSS.
- **Admin Panel:** Separate interface for restaurant/app owners to add, update, or remove food items from the database.
- **Secure Backend:** RESTful API built with Node.js and Express, connected to MongoDB.

---

## 🛠️ Tech Stack

**Frontend:**
- React.js (Vite)
- CSS3 (with responsive layouts)
- Context API (State Management)

**Backend:**
- Node.js
- Express.js
- MongoDB & Mongoose (Database)

**Deployment:**
- Frontend: **Vercel**
- Backend: **Render**
